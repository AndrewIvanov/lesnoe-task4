# Лесное — практическое задание № 4
Учебный сайт бронирования загородных домов. HTML, CSS, ванильный JavaScript (ES-модули). Без npm, сборки, внешних сервисов и оплаты.

## Запуск
Распакуйте архив. На macOS откройте Terminal, перейдите в папку проекта и выполните `bash start.command`. На Windows запустите `start.bat`. Требуется Python 3. Откроется http://localhost:8000. Альтернатива: расширение Live Server в VS Code, открыть index.html через него. Двойной щелчок непосредственно по index.html не подходит для ES-модулей. Для остановки сервера нажмите Ctrl+C. Если порт занят, выполните `python3 -m http.server 8001` и откройте http://localhost:8001.

## Функции
8 домов, 2 изначально заняты. Общие данные схемы и списка, фильтры по вместимости и цене, выбор, расчёт, проверка полей, подтверждение, отмена, сохранение в localStorage, сброс демо. Бронирование целиком до отмены, без календаря и реальной оплаты. Данные хранятся в конкретном браузере и origin.

## Нейросеть и промпты
Использована ChatGPT. Основные запросы из задания:
- Создай сайт бронирования загородных домов на HTML/CSS/ванильном JS, со схемой, восемью домами и двумя занятыми.
- Добавь синхронные фильтры, выбор, расчёт стоимости и проверку целых значений.
- Добавь сохранение в localStorage, отмену, сброс и адаптивный интерфейс.

## Проверка
1. Выберите дом 1 на схеме, проверьте выделение списка. Выберите 2 ночи: 7 800 ₽. Подтвердите дважды: должна появиться одна бронь.
2. Обновите страницу: бронь и занятость остаются. Отмените: дом свободен.
3. Дом 3 и 7 недоступны. Попробуйте пустой выбор, 0, 31, дробные ночи, превышение вместимости.
4. Фильтр 8 гостей и до 5000 ₽ даёт пустой список и схему. Сброс возвращает все дома.
5. Проверьте клавишами Tab/Enter и на узком экране. Сброс демо требует подтверждения.

## Публикация и сдача
Создайте публичный репозиторий GitHub, загрузите содержимое папки (index.html должен лежать в корне). Settings → Pages → Deploy from a branch → main → /(root) → Save. Откройте выданную ссылку и повторите проверку. Сдайте ссылку на сайт и репозиторий. Публикация требует вашего аккаунта GitHub; архив сам по себе сайт не публикует.
